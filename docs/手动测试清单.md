## 已知限制与说明（如实标注）

1. **多智能体生成偏慢且偶发失败**：真实 LLM 生成 6 类资源需数分钟；DeepSeek API 偶发空响应/连接中断会导致某 agent 失败（系统会重试/降级，可点"重新生成"）。
2. **侧边栏课程上下文为静态**："人工智能导论 · 68%" 是硬编码展示，非实时。
3. **登出按钮为装饰**：无鉴权系统，身份是 localStorage UUID。
4. **活动热力图 / 学习趋势为前端演示数据**（随机生成），非真实行为追踪。
5. **`/docs` 无 UI 页**：Phase 5 的"文档"指项目文档（README/docs），非前端路由。
6. **画像持久化为部分**：聊天画像实时更新存于前端 store 与后端内存；`/settings` 保存的画像写 profile-service。
7. **无鉴权**：所有 API 默认开放（`API_KEY` 为空时）。
